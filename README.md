# Mini-Proyecto Ágil: Calculadora con Integración Continua

Repositorio para la simulación práctica de entrega continua y calidad de software mediante marcos de trabajo ágiles.

## Prácticas de Calidad Integradas

### 1. Coding Standards (Estándar PEP 8 y Linter Flake8)
* **Qué práctica se aplicó:** Definición del estándar de codificación PEP 8 mediante el archivo de configuración `.flake8`.
* **Qué problema evita:** Evita inconsistencias de formato, líneas excesivamente largas y malas prácticas de sintaxis entre los desarrolladores. Garantiza que el código sea legible y mantenible desde el primer momento.
* **Relación con el marco ágil:** En agilidad, el código pertenece al equipo. Tener estándares compartidos reduce el retrabajo en las revisiones y agiliza la integración de nuevos incrementos sin discusiones innecesarias de formato.

### 2. Feature Branching, Pull Request y Code Review
* **Qué práctica se aplicó:** Desarrollo de una nueva funcionalidad en una rama aislada (`feature/multiplicacion-division`), apertura de Pull Request y revisión técnica documentada antes de integrar a la rama principal (`main`).
* **Qué problema evita:** Evita la integración tardía y los conflictos destructivos de código. Asegura que ningún cambio entre a producción sin haber sido revisado previamente.
* **Relación con el marco ágil:** Previene la integración tipo "Big Bang" (unir meses o semanas de trabajo al final sin validación). Fomenta entregas pequeñas, frecuentes y de alta calidad técnica.
